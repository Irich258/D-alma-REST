TESTE D'ALMA — AR

Ficheiros:
- index.html
- 3DModel.usdz

PUBLICAR NO GITHUB PAGES
1. Crie ou abra um repositório.
2. Envie index.html e 3DModel.usdz diretamente para a raiz do repositório.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: /(root).
7. Save.
8. Aguarde o deployment e abra o endereço publicado no Safari do iPhone/iPad.
9. Toque em “Ver prato na minha mesa”.

Observação:
Este protótipo contém apenas USDZ, portanto o AR foi preparado para iPhone/iPad. Para Android, adicione futuramente uma versão GLB e use <model-viewer>.
